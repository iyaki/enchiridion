## Why should you choose Quasar?

### All platforms, one codebase

SPA, SSR, SSG, PWA, browser extension, mobile and desktop apps from the same code, with a CLI that ties the build modes together.

### Accessible components

More than 120 fast Vue.js components with WAI-ARIA semantics, keyboard navigation and focus management built in.

### Built for AI agents

The docs and API ship inside the packages: an MCP server hands your coding agent the exact versions your project runs, offline.

### Great documentation

Live examples and a full API for every component, plugin and build mode, kept in step with each release. Every star-pilot needs a good manual.
