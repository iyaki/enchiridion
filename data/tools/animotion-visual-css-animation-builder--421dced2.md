Animotion lets you **create CSS animations visually**, by dragging, resizing, rotating, clipping and more, including a **keyframes editor**, a collection of **ready-to-use animations** and **29 built-in easings**

This app works better on larger screens and modern web browsers

## Updates

- **Tooltips Help** — Hover over buttons to find out what they do. You can turn tooltips on or off whenever you like.
- **Cleaner Code** — Percentage steps with the same values are now grouped together for a concise generated code.
- **Transform Snapping** — Added snapping and guidelines to the transform tool.
- **Keyboard Shortcuts** — You can now use Ctrl+Z for undo, Ctrl+Shift+Z or Ctrl+Y for redo, left/right keys to navigate between keyframes, Ctrl+X to cut, Ctrl+C to copy, Ctrl+V to paste, and backspace/del/delete to delete. For Mac users, use the Command key.
- **New domain name** — Now you can access Animotion by visiting animotion.dev or www.animotion.dev.
- **Added Undo/Redo** — Better experience and more control, now you can easily undo or redo actions.
- **GitHub Dark Theme** — Now, the code editor has a GitHub dark theme, giving it a fresh look with new colors and better syntax highlighting.
- **Keyframe Automation** — Keyframes are now automatically created as you edit, based on the playhead's location.
- **Dark Mode** — New dark theme added. Now, night owl developers can reduce eye strain by switching between light and dark with a simple click.
- **Motions Gallery** — A new tab with a collection of ready-to-use animations. You can simply choose one, copy the CSS code, and use it without changing anything, or customize it to fit your needs.
- **Edit Animation Button** — Previously, the STOP button on the player was used to stop the animation and automatically trigger the editing mode. Now, there's a separate button specifically for manual animation editing, offering a stronger sense of control and less confusion.
- **First Beta Release** — This is the very first version of the app, like a test. It includes the basic features we've built so far.
