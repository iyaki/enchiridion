**Archive.today** is a time capsule for web pages!

It takes a 'snapshot' of a webpage that will always be online even if the original page disappears.

It saves a text and a graphical copy of the page for better accuracy

and provides a short and reliable link to an unalterable record of any web page

including those from Web 2.0 sites:

- [https://archive.ph/2014.06.26/google.com/maps/…](https://archive.ph/2014.06.26/https://www.google.com/maps/@-12.1858563,96.8293918,366m/data=!3m1!1e3)

This can be useful if you want to take a 'snapshot' of a page which could change soon: price list, job offer, real estate listing, drunk blog post, ...

Saved pages will have no active elements and no scripts, so they keep you safe as they cannot have any popups or malware!

search queries by example

- [microsoft.com](https://archive.ph/microsoft.com)for snapshots from the host microsoft.com
- [.microsoft.com](https://archive.ph/*.microsoft.com)for snapshots from microsoft.com and all its subdomains (e.g. www.microsoft.com)
- [http://twitter.com/burgerking](https://archive.ph/http://twitter.com/burgerking)for snapshots from exact url (search is case-sensitive)
- [http://twitter.com/burg*](https://archive.ph/http://twitter.com/burg*)for snapshots from urls starting with http://twitter.com/burg
