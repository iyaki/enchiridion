## Compatibility

Loading.io's CSS spinner uses CSS Animation, which is wildly supported by all modern browsers such as Google Chrome and Mozilla Firefox. However, Microsoft Internet Explorer version earlier than 10 don't support CSS Animation.

To support older IE, you have to use GIF format image. Choose one from loading.io's [online spinner gallery](https://loading.io/spinner/) and you can customize an unique loader GIF with our icon editor easily.

Some older browsers need prefix like '-webkit-' to use CSS Animation. To minimize file size, we omitted all vendor prefix in loaders' CSS, but you can customize this by building CSS from source. See [README.md](https://github.com/loadingio/css-spinner) in the repo for more information.
