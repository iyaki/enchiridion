CSS data visualization framework

[Quick Start](https://chartscss.org/docs/) [GitHub Repo](https://github.com/ChartsCSS/charts.css)

**Charts.css** is a modern CSS framework. It uses CSS utility classes to style HTML elements as charts.

The [source code is available on GitHub (opens new window)](https://github.com/ChartsCSS/charts.css). If you like the project, please consider to star the repo on GitHub.
