El Opportunity Solution Tree (OST), también conocido como Árbol de Soluciones de Oportunidades, es una herramienta visual poderosa que se origina en el libro “Continuous Discovery Habits”.

Este enfoque proporciona una forma clara y efectiva de mapear el camino hacia los resultados deseados en el marco del descubrimiento continuo.

# **Definiendo el Camino hacia el Resultado Deseado**

El proceso de descubrimiento comienza con la definición de un Outcome claro (o, dicho en castellano, un resultado, típicamente un item, que esperamos que aporte valor).

Este Outcome actúa como la brújula que establece el alcance y la dirección para todo el proceso.

# **Mapeo del Espacio de Oportunidades**

Una vez establecido el Outcome, la atención se dirige hacia el mapeo del espacio de oportunidades. Esta fase implica explorar y visualizar las áreas donde se pueden identificar oportunidades. El Árbol de Soluciones de Oportunidades sirve como una guía visual durante este proceso, ayudando a destacar posibles caminos y direcciones.

# **Explorando Soluciones**

Esta fase implica creatividad y la búsqueda de enfoques innovadores para abordar las oportunidades identificadas.

# **Visualizando Posibles Vías**

Los Árboles de Soluciones de Oportunidades ofrecen una representación visual clara y concisa de las posibles vías hacia lograr el Outcome. Cada rama del árbol representa una dirección específica o enfoque para abordar las oportunidades. Esta visualización simplifica la toma de decisiones al proporcionar una visión general de las opciones disponibles.

# **Combinando Árboles con las Cartas Value Agile Blackjack**

El “Árbol Solución Oportunidad" se maximiza al combinarlo con la tipología de cartas que llamé Value Agile Blackjack, [de la que os hablé la semana pasada](https://click.convertkit-mail2.com/mvu53oeqr4t5hgelpz8cmheoqklqq/8ghqhohl522rlpak/aHR0cHM6Ly8yMzMtYWNhZGVteS5jay5wYWdlL3Bvc3RzL3RpcG9zLWRlLXZhbG9yLWFnaWwtbGEtZGluYW1pY2EtdmFsdWUtYmxhY2tqYWNrLXRoaXNpc3RoZWFnaWxld2F5) y que tipifica 9 posibles valores.

La combinación con el Value Agile Blackjack, agrega capas, detalle y claridad al proceso, asegurando que cada paso contribuya significativamente al logro del Outcome deseado.
