## Fast Startup

Based on Rust, the build speed is extremely fast, bringing you the ultimate development experience.

## Lightning HMR

With a built-in incremental compilation mechanism, HMR is extremely fast and fully capable of developing large-scale projects.

📦

## Webpack Compatible

Compatible with the architecture and ecosystem of webpack, no need to build the ecosystem from scratch.

🎨

## Batteries included

Out-of-the-box support for TypeScript, JSX, CSS, CSS Modules, Sass, and more.

🛠️

## Production Optimization

By default, various optimization strategies such as tree shaking and minification are built in.
