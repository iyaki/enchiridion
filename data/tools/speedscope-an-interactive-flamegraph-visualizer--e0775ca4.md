👋 Hi there! Welcome to 🔬speedscope, an interactive [flamegraph](http://www.brendangregg.com/FlameGraphs/cpuflamegraphs.html) visualizer. Use it to help you make your software faster.

Drag and drop a profile file onto this window to get started, click the big blue button below to browse for a profile to explore, or click here to load an example profile.

See the [documentation](https://github.com/jlfwong/speedscope#usage) for information about supported file formats, keyboard shortcuts, and how to navigate around the profile.

speedscope is open source. Please [report any issues on GitHub](https://github.com/jlfwong/speedscope/issues).
