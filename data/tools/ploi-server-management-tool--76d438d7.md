## Why should you pick Ploi?

Ploi offers many features to make your life as developer as easy as possible to setup sites and servers.

### Fast Provisioning

Quickly provision servers and deploy sites with DigitalOcean, UpCloud, Vultr, Linode, Scaleway, AWS EC2, or Custom VPS.

### Accessible Interface

A UI that is easy on the eyes. Clean, easy to use, fantastic. Built by developers, for developers.

### SSL Certificates

LetsEncrypt support with 1-click install for your websites. Protect your website with SSL within 1 minute, for free!

### Installed By Default

We install NGINX, PHP, and Redis by default to help you get started quickly.

### SSH Keys

Each server gets its own unique encrypted key-pair generated.

### Easy Queues

Forget manually creating supervisor config files, Ploi takes care of it!
