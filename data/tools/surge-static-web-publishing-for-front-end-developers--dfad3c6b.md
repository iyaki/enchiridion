## Blends with your build tool

Surge augments the tools you already love. Deploy using your favourite build tool, like Grunt, Gulp, or through an npm run script. To make it a `devDependency`, run:

### [Grunt plugin](https://surge.sh/help/deploying-a-grunt-project)

[Install the ](https://surge.sh/help/deploying-a-grunt-project)[`grunt-surge`](https://surge.sh/help/deploying-a-grunt-project)[ plugin, and your project is ready to use ](https://surge.sh/help/deploying-a-grunt-project)[`grunt deploy`](https://surge.sh/help/deploying-a-grunt-project)[.](https://surge.sh/help/deploying-a-grunt-project)

### [Gulp plugin](https://github.com/surge-sh/gulp-surge)

[Install ](https://github.com/surge-sh/gulp-surge)[`surge`](https://github.com/surge-sh/gulp-surge)[ as a devDependency, and you’re ready to use it in your Gulpfile.](https://github.com/surge-sh/gulp-surge)

### [Git Hooks](https://surge.sh/help/deploying-continuously-using-git-hooks)

[Deploy every time you ](https://surge.sh/help/deploying-continuously-using-git-hooks)[`push`](https://surge.sh/help/deploying-continuously-using-git-hooks)[ to GitHub, but without any branch juggling.](https://surge.sh/help/deploying-continuously-using-git-hooks)

### [npm run scripts](https://surge.sh/help/getting-started-with-surge)

[Install the Surge CLI tool, and your project is ready to use in your ](https://surge.sh/help/getting-started-with-surge)[`package.json`](https://surge.sh/help/getting-started-with-surge)[.](https://surge.sh/help/getting-started-with-surge)

### [Jekyll](https://surge.sh/help/deploying-a-jekyll-project)

[Don’t worry about branch-juggling or plugin limitations when publishing Jekyll sites—compile locally and publish to Surge.](https://surge.sh/help/deploying-a-jekyll-project)

### [Static Site Generators](https://surge.sh/help/getting-started-with-surge)

[Hand-coded HTML, CSS, and JS? Using a highly customised static site generator? Deploy it quickly with the Surge CLI.](https://surge.sh/help/getting-started-with-surge)

### [Node.js](https://surge.sh/help/getting-started-with-surge)

[Build Surge into your own tool by installing it as a development dependency.](https://surge.sh/help/getting-started-with-surge)

### [CI services](https://surge.sh/help/integrating-with-travis-ci)

Use Surge alongside CI services like [Travis CI](https://surge.sh/help/integrating-with-travis-ci), [CircleCI](https://surge.sh/help/integrating-with-circleci), [Codeship](https://surge.sh/help/integrating-with-codeship), and more for automatic deployment.
