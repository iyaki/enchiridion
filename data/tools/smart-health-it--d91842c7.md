The SMART vision of substitutable healthcare applications holds many benefits for app developers, healthcare providers, patients, healthcare institutions and public health. Many projects and products incorporate SMART on FHIR APIs, including:

- Apple Health Records API
- HL7 FHIR API
- Argonaut FHIR API
- Sync for Science
- CMS Blue Button 2.0
- Microsoft Azure SMART API
- CMS ACO Beneficiary Claims Data pilot
- CMS Data at the Point of Care pilot
- Commure FHIR API and Commure Bulk Data API
