Fusio is an open source API management platform which helps to create innovative API solutions.

[Subscribe](https://www.fusio-project.org/#) [Demo](https://www.fusio-project.org/demo)

### API management

Fusio provides a powerful [backend](https://www.fusio-project.org/demo) app to control and monitor your API.

### Developer portal

Fusio provides a [developer portal](https://demo.fusio-project.org/apps/developer/) app where developer can register to use your API.

### API Generator

Fusio provides multiple generators to build complete APIs without coding from different sources.

### Monetization

Fusio provides a simple payment system to charge for specific routes.

### SDK generation

Fusio can automatically generate a client SDK for your API based on the defined schema.

### Rate limiting

Fusio provides a way to rate limit requests based on the user or app.

### Schema generation

Fusio provides an endpoint to automatically generate [OAI](https://www.openapis.org/) and [RAML](https://raml.org/) specifications.

### Event support

Fusio contains a subscription layer which helps to build pub/sub for your API.

### OAuth2 authorization

App developer can obtain an access token to access non-public API endpoints.
